# Виджет-Обои для Windows 11 (ЕГЭ)

Интерактивный виджет для рабочего стола Windows 11, который работает как обои с Wallpaper Engine. Предназначен для подготовки к ЕГЭ по трём предметам:

* Математика (профиль)
* Информатика
* Русский язык

## Описание

Виджет отображает три блока с заданиями по каждому предмету. Каждый блок содержит набор заданий в виде кнопок.

Каждое задание имеет состояние:

* не начато
* есть проблемы
* готово

## Функционал

* Изменение статуса задания по двойному нажатию ЛКМ
* Визуальное отображение состояния (цветовая индикация)
* Автоматическое сохранение прогресса в памяти
* Восстановление состояния после перезапуска
* Статус-бар для быстрого обзора прогресса по каждому предмету

## Интерфейс

* 3 отдельные секции: Математика, Информатика, Русский язык
* В каждой секции 19 или 27 заданий в зависимости от предмета
* Цветовая схема:

  * красный: не начато
  * жёлтый: есть проблемы
  * зелёный: готово
